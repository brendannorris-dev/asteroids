# Pygame Asteroids Simulator

A modular 2D arcade simulator built using Python and Pygame. Projected served as a foundational exploration into game loop mechanics, managing states, and coordinate physics.

## Technical Implementation & Architecture
* Vector Mathematics: Implemented 2D velocity and acceleration vectors to manage fluid player movement, logic for screen-wrapping, and collision trajectory.
* Objected Oriented Design: Utilized class inheritance structures to manage game entities across the codebase.
* Collision Detection: Developed circular hitbox calculation systems to accurately flag overlapping game objects within active render loop.
* Telemetry & State Logging

## Frameworks & Architecture
* Boot.dev Core Architecture: Built utilizing foundational backend starter-kit to explore object-oriented structure optimization
* Pygame
